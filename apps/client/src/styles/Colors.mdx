# Couleurs utilisées dans le projet

Toutes les couleurs proviennent du **Système de Design de l'État (DSFR)**, via les
**tokens de décision**. Chaque pastille montre, de haut en bas :

1. le **hex** (thème clair), la même valeur que dans Figma
2. le **nom** de la décision
3. la **variable** à écrire selon le contexte

Exemple concret pour `text.default.error` :

```tsx
// en className (Tailwind), on écrit la variable CSS
<p className="text-(--text-default-error)">Erreur</p>;

// en style={{}} (TS), on importe la décision, typée et autocomplétée
import { colors } from '@codegouvfr/react-dsfr';

<p style={{ color: colors.decisions.text.default.error.default }}>Erreur</p>;
```
